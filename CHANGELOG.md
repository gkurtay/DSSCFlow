# Changelog

## 1.0.0 - 2026-08-16

First public research-software release accompanying the DSSC16 study.

- TD-DFT spectrum reconstruction and Beer-Lambert absorptance.
- Source-conditioned PCF/PCC/PCB metrics and wavelength-band attribution.
- Complete 2^4 factorial-effect analysis.
- Source and Gaussian-broadening robustness workflows.
- Exact and epsilon-Pareto decision analysis.
- Reproducible command-line interface (`dsscflow`).
- Local browser-based graphical interface (`dsscflow gui` / `dsscflow-gui`) using the same numerical core as the CLI.
- Bundled DSSC16 demonstration/reproduction dataset.
- CSV upload, interactive spectra/ranking/factorial/Pareto/robustness views, and numerical ZIP export in the GUI.
- Configurable Beer-Lambert concentration and optical path length in the GUI.
- Automated numerical publication-regression, GUI-backend, local-port, export, and author-attribution tests.
- Visible author, affiliation, email and ORCID information in the graphical interface and citation metadata.
